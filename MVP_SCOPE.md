# MVP Scope

## MVP Goal

Create a professional MCP-native app-building workspace where users bring their own AI clients and connect only the external infrastructure services needed to build, store, preview, and deploy apps.

## Included in MVP

### Project dashboard

Users can create and manage projects from a clean dashboard.

### Project workspace

Each project includes:

- overview
- blueprint
- tasks
- files
- MCP connection details
- integrations
- activity log
- preview/deployment status

### MCP server foundation

Expose project context and controlled actions through MCP resources and tools.

### Role cards

Users can select or customize structured roles such as Product Manager, Designer, Frontend Engineer, Backend Engineer, QA Reviewer, Security Reviewer, and DevOps Engineer.

### Task system

AI clients can create, update, and complete tasks through MCP tools.

### Blueprint system

AI clients and users can maintain a structured source of truth for the app.

### File workspace

AI clients can list, read, and write project files according to permissions.

### Approval queue

Risky actions require user approval before execution.

### Infrastructure connector pages

Users can connect deployment and database services. The MVP can start with placeholder connector flows and clean interfaces, then add provider-specific OAuth/API integrations.

## Initial Integrations

### Deployment

- Vercel
- Netlify
- Cloudflare Pages

### Database

- Supabase
- Neon
- Firebase

## Deferred Features

- Marketplace.
- Hosted AI credits.
- Autonomous background agents.
- Automatic AI debates.
- Multi-user real-time collaboration.
- Advanced visual editor.
- White-label agency portals.

## MVP Quality Bar

The product should feel professional from day one. The MVP should prioritize polished information architecture, clear empty states, strong onboarding, predictable permissions, and a trustworthy audit trail.
